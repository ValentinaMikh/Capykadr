# CapyKadr

Конструктор промтов для маскотов-капибар КуулКлевер (папа, мама, сын) под Nano Banana.
Промт собирается в браузере по готовым шаблонам — без нейросетей.

Сайт: https://valentinamikh.github.io/Capykadr/

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html`, `styles.css`, `app.js` | Интерфейс: вход, конструктор с холстом, «Мои промты», галерея, админка |
| `data.js` | Справочники: персонажи, одежда по сезонам, позы, эмоции, локации, свет, кадр, действия, запреты |
| `builder.js` | Сборка промта и инструкции по справочникам, правила доступности вариантов |
| `config.js` | Адрес проекта Supabase и публичный ключ (права ограничены RLS) |
| `supabase/setup.sql` | Таблицы, правила доступа, проверка пароля команды, хранилища |
| `vendor/` | Библиотека Supabase, внешние CDN не нужны |

## Как устроено

| Что | Где |
|---|---|
| Вход | Supabase Auth: любая почта + пароль команды. Пароль проверяет триггер `private.before_signup`, хеш лежит в `private.settings` |
| Мои промты | `prompt_history`, видит только автор |
| Галерея | `publications` + картинки в закрытом хранилище `works`, отметки — `publication_likes` |
| Аналитика | `events` (копирование промта, эталона, оценки, публикации). Читает только админ |
| Эталоны маскота | Картинки в закрытом хранилище `refs`, список — `ref_images`. Загружает админ в «Админке» |
| Админ | Таблица `admins` (почта). Смена пароля команды — функция `set_team_password` |

## Как добавить вариант

Всё в `data.js`: новая поза — строка в `POSES`, одежда — в `OUTFITS`, локация — в `LOCATIONS`.
Английский текст пишется в поле `en`. Ограничения: `who` (кто может), `outfit` (с какой одеждой).
